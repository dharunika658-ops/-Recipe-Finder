# Recipe Finder

A simple web application that helps users search and explore different recipes.

## Features

- Search for recipes
- View recipe details
- Display ingredients
- View cooking instructions
- User-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Search for your favorite recipes.

## Project Purpose

This project was developed to practice frontend web development, JavaScript, and API integration.
